# PoolHub Documentation Hub

Thư mục này tổng hợp tài liệu chuẩn để cả người và AI nắm được ngữ cảnh hệ thống PoolHub.

## Cấu trúc
- `ai/SYSTEM_CONTEXT.md`: Bối cảnh hệ thống, phạm vi nghiệp vụ, hiện trạng code.
- `ai/AI_DEVELOPMENT_RULES.md`: Rule bắt buộc khi AI phát triển tính năng.
- `ai/DOC_SOURCE_MAP.md`: Danh mục tài liệu hiện có và mức độ ưu tiên (source of truth).

## Mục tiêu
- Đồng bộ cách hiểu giữa tài liệu thiết kế và code triển khai.
- Giảm sai lệch khi AI tạo API/DB/luồng nghiệp vụ.
- Tạo chuẩn để mở rộng backend .NET theo đúng nghiệp vụ PoolHub.
